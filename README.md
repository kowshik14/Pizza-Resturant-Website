# 🍕 PizzaPalace - A Full-Stack Pizza Restaurant Website

## Project Overview
**PizzaPalace** is a full-stack, dynamic website designed to streamline the online experience for a modern pizza restaurant. Built with a combination of front-end and back-end technologies, this website offers users a seamless interface for browsing the menu, placing orders, and interacting with the restaurant.

## Key Features
- **Responsive Design:** Optimized across all devices using Bootstrap for a mobile-first approach.
- **Interactive UI:** Engaging JavaScript interactions for smooth navigation and a rich user experience.
- **Online Ordering System:** Secure and efficient order management powered by ASP.NET and SQL database integration.
- **Menu Management:** Dynamic display of the restaurant’s menu with options to customize pizzas, select toppings, and add items to the cart.
- **User Authentication:** Login and registration system for both customers and administrators.
- **Admin Dashboard:** Backend panel for managing orders, updating menu items, and viewing customer data.
- **Cache & Cookies Management:** Implements caching for faster page load times and cookies for saving user preferences and login sessions, enhancing user experience and performance.

## Project Highlights
- Integrated **SQL Server** for real-time data handling, allowing the website to manage user accounts, orders, and product inventory.
- Utilized **ASP.NET** for robust server-side logic, handling customer requests and order processing efficiently.
- **Cache and Cookies** functionality to store user sessions, cart items, and other user preferences for a personalized and seamless experience.
- Clean and intuitive user interface with modern **Bootstrap 4** styling for ease of use and aesthetic appeal.

## How to Run
1. Clone the repository.
2. Open the solution in **Microsoft Visual Studio**.
3. Restore the **NuGet** packages and ensure SQL Server is set up.
4. Run the project on **IIS Express** or a local server.
5. Enjoy the full PizzaPalace experience!
